# ADR-0004: React Frontend Stack & Reusable Design System

- **Status**: accepted
- **Date**: 2026-10-05
- **Deciders**: User, Antigravity Agent

## Context & Problem Statement
The WebUI requires high-performance rendering for:
1. Real-time streaming chat with token markdown parsing and interactive tool approval dialogs.
2. Complex multi-node property graph inspection (Kùzu lineage canvas).
3. Flexible docking, internal tabs, and collapsible accordion panes.
4. A reusable visual style guide and component library that can be exported or reused for new applications developed with AICO.

## Decision Drivers
- Rich ecosystem of interactive components (canvases, tabs, virtualization).
- Clean separation of design tokens (colors, typography, spacing, status indicators).
- Cross-project reusability for projects generated by AICO.

## Considered Options
1. **Option A (Chosen)**: React + Vite + Tailwind CSS + Radix UI primitives, with design tokens and core components extracted into a reusable `@aico/ui` library.
2. **Option B**: Svelte 5 + Vite + Tailwind CSS.
3. **Option C**: Vanilla HTML/CSS/JavaScript with Web Components.

## Decision Outcome
Chosen option: **Option A**. 
React combined with Vite, Tailwind CSS, and Radix UI primitives provides the highest leverage for building complex developer tool interfaces (dockable panels, internal tabs, virtualized chat logs, interactive Cytoscape/WebGL canvases). 

To fulfill the requirement for a reusable visual language across projects built with AICO:
- We establish an **AICO Design System (`@aico/ui`)**:
  - Semantic Tailwind design tokens (dark mode defaults, status accents for verified/red/blocked requirements).
  - Standalone component library (`<Button>`, `<Card>`, `<Badge>`, `<Accordion>`, `<Tabs>`, `<StatusPill>`).
  - New projects created via AICO can import `@aico/ui` or adopt its Tailwind configuration preset to maintain a cohesive, high-polish visual language.

### Positive Consequences
- Robust ecosystem support for graph visualization and split-pane window managers.
- Clear path for reusable UI components across developer projects.
- Fast local development with Vite HMR.
